# 《一矛到底》v2.0.0 · 降噪版多巴胺竞技场

本版不改核心玩法与数值，专门解决 v1.9.0 长时间游玩时的视觉疲劳：保留多巴胺竞技场的传播辨识度，但把持续高饱和、高发光改成“普通状态克制，高光事件爆发”。

- 背景素材平均HSV饱和度降低约30%，增加冷色稳定蒙层；动态舞台光束由5条降为3条，速度线数量与透明度同步降低。
- 普通/安全平台主动降饱和，高分台、回血台、移动台和皇冠台保持高辨识高亮；历史平台进一步降饱和和透明度。
- HUD 改为统一深蓝灰玻璃底，减少紫/粉/青同时争抢；总分仅保留金色核心强调，Combo 用细粉色边条而非整块高饱和面板。
- 普通飞渡的加分反馈改成短促暗底浮层；10分台/高Combo使用中等爆裂，20分台、移动台、高阶Combo、越台才使用完整漫画爆裂。
- 普通得分反馈时长缩短，高光得分保留较长展示；受伤红框强度降低。
- 菜单、暂停、玩法说明、结算统一采用低饱和深蓝灰面板，主按钮保留暖金橙作为唯一强CTA。

# 《一矛到底》v1.9.0 · GREAT与流动挑战台

- 命中分为 PERFECT / GREAT / 普通命中：GREAT 可击杀普通敌人，铁卫与逐风将仍要求 PERFECT；只有 PERFECT 延续 Combo。
- 击杀额外加分：弓手/疾射/游弓 +2，铁卫/盾卫 +3，逐风将 +5；多杀只累加，不做倍率。
- 2000m 后低概率出现纯左右匀速往返的流动挑战台：±34px、42px/s、基础20分、无敌人；成功落台自动 PERFECT。
- 流动台投矛使用未来X预测，绳索飞行与站立阶段跟随平台；不加入任何上下移动。

# v1.8.1 — 回满血灵药 / 天然高分台

- 回血药改为**一次直接回满 100 HP**；因为单次价值显著提高，回血路线生成概率同步收紧为高血12%、中血20%、低血42%、危急60%，近期连续受伤时至少50%。
- 平台新增天然基础分：普通平台1分，部分特殊/稀有平台天然为5/10/20分。回血台固定5分，风险/穿透台固定10分，Boss/皇冠台固定20分；普通台也会按距离档位小概率刷出5/10/20分台。
- Perfect Combo 仍保持 1→2→4→8→16→32，但只把“高于1分”的部分叠加到平台基础分。例如10分台在Perfect Combo第4档（8分）时，本跳为10+7=17分；普通1分台则仍严格是1/2/4/8/16/32。
- 越台额外+32保持不变。

# v1.8.0 规则更新

- 命中分三级：**PERFECT**（最高精度）、**GREAT**（较宽的致命窗口）、普通命中。GREAT 可击杀普通敌人；铁卫/精英仍要求 PERFECT。普通命中依然能挂绳飞渡，但敌人会存活并在落地后攻击。
- **Combo = 连续 PERFECT**。非 PERFECT 飞渡会清零 Combo；被攻击本身不会清零。
- 普通台基础1分；部分平台天然为5/10/20分。Perfect Combo 的增量仍按 1→2→4→8→16→32 计算，越台额外 +32。
- 为适配“普通命中留敌”的新风险，近战首刀/频率与敌人伤害已重新平衡。
- 六种小兵素材方向已统一朝左，错误朝右的素材仅做镜像修复。

## v1.9.0 流动挑战台

距离达到 **2000m** 后，候选路线中会低概率出现左右匀速往返的“流动挑战台”。它不会上下移动，也没有敌人；基础分固定 **20分**。成功挂索并真正落到流动台时，本跳自动作为 **PERFECT** 结算并延续 Perfect Combo。

平台水平移动幅度为 `±34px`，速度 `42px/s`，从左端到右端约1.62秒、完整往返约3.24秒。投矛会根据标枪飞行时间预测平台未来X坐标，绳索拉人阶段也持续跟随平台，因此玩家面对的是可读的匀速移动目标，而不是判定延迟。


## v1.8.0 蓄力音效

蓄力音效现在是一条每次都从头播放的固定时间轴，而不是随帧连续扫频。按下后从低层基音起步，在 **0.30 / 0.60 / 0.90 / 1.20 秒**进入下一层，并各有一个短促的上扬提示音；玩家可以把它当成隐藏的“声音刻度尺”。松手或取消会立即终止当前蓄力声音以及尚未到时的后续提示，因此下一次蓄力必定重新从第一层开始。该时间轴由 WebAudio 的绝对时钟调度，不随 FPS 漂移。

## v1.7.0 数值精修

本版不增加新系统，重点修正隐藏手感参数：远档基准间距改为836px，教学容错逐跳收窄，残敌首刀/连刺进一步调整为0.34/0.30秒，后续远程攻击周期设1.25秒硬下限，并把回血路线改为按HP与近期受伤压力动态生成。完整参数见 `TUNING.md`。

## 先玩

直接用桌面浏览器打开根目录的 **`one-spear-play.html`**。这是完整内嵌的离线试玩版，不需要联网、安装依赖或补图片。Windows 也可双击 `START_GAME.bat`。

手机建议用静态服务器打开，而不是依赖聊天软件的 HTML 附件预览：

```bash
node scripts/serve.mjs dist 4173
```

电脑打开 `http://localhost:4173`。手机与电脑接入同一局域网后，使用电脑的局域网 IP 加 `:4173` 访问；需允许本机防火墙接收该端口连接。竖屏进入时游戏舞台会自动旋转 90° 并继续运行，不显示“请旋转手机”阻塞层。静态托管可直接上传 `dist/` 内的内容。

本工程不包含公共在线部署地址，也没有把文件上传到你的服务器或修改你的电脑。

## 正常开发：Phaser 3 + TypeScript + Vite

建议 Node.js 20.19+ 或兼容的新版本；项目固定声明 Phaser 3.90.0、TypeScript 5.9.2、Vite 6.3.5。这里固定使用 Phaser **3**，不跟随最新主版本自动升级。

```bash
npm install
npm run dev
npm run build:vite
npm run preview
```

`build:vite` 是严格入口：执行 TypeScript 检查和真正的 Vite 构建，依赖缺失时直接失败，不会伪装成功。联网环境中首次安装成功后，请提交实际生成的 `package-lock.json`。本包未伪造未经解析的锁文件。

便捷命令：

```bash
npm run build
```

有 Vite 依赖时，执行正常 Vite 构建；无依赖但本机已有 TypeScript 时，**明确输出离线 fallback 提示**，编译共享玩法并生成离线版。`npm run dev` 在无依赖时启动预构建目录的静态服务器，**不提供 Vite/HMR**。本轮这两个便捷命令实际走的是此分支。

```bash
npm run build:offline
npm test
```

`build:offline` 使用真实 TypeScript 编译器输出 CommonJS，然后用小型本地模块封装器生成零依赖 HTML。`npm test` 读取该构建产物，因此修改源码后先构建再测试。

## 操作

手机：**不需要点平台，也不需要拖动选路**。游戏中任意非 UI 位置都相当于同一个巨大蓄力按钮：按住开始蓄力，按得越久有效水平射程越远，松手投矛。系统根据这一刻的理论射程自动匹配距离最接近的平台；如果射程误差超出命中容错，仍会投空坠崖，不会把明显错误的距离偷偷吸附回来。

**前三次成功跳跃属于手感教学**：第 1 跳固定近距离单人台（约 0.39 秒），第 2 跳固定中距离双人穿透台（约 0.75 秒），第 3 跳固定远距离回血台（约 1.16 秒），并显示下方力度条。第三次成功落地后，弹出“你已经完全学会了，提示就取消了哦！祝少侠好运！”；随后力度条、目标准星和教学高亮全部收起，正式阶段只靠距离感与按压时长。

蓄力采用统一单调线性映射：0～1.28 秒对应 0～100% 力度；有效水平射程为 `120 + 770 × 力度` 逻辑像素，满蓄力封顶、不回弹。**全过程不显示抛物线/落点引导线。**桌面鼠标与触摸完全一致；空格按住/松开也可蓄力投掷，P/Esc 暂停，R 在结算或调试模式重开。

精准命中重甲的头部可一击破甲；普通身体命中只会造成一次伤害。盾卫预警圈显示“开”时可穿过，显示“守”时会挡枪。双敌或三敌平台使用沿弹道布置的阶梯，一次正确投掷可以真正连续命中多个敌人。**只要标枪扎中有效目标，玩家就会飞过去；如果同台还有残敌，落地后残敌立即切近战连续捅刺，人数越多掉血越快。**

药瓶在落地时自动恢复 32 气血，满血不会产生超额生命。**投空、盾挡或未能扎牢都会让玩家继续跃出，随后坠下悬崖并结束本局。**敌人的预警圈快满时应尽快出手；敌箭锁定**发射瞬间的位置**，及时飞走会让箭落空。

从第 4 跳开始，已经进入视野的前方平台会成为持久世界对象：如果你先看到“后面是双人台/回血台”，落到前面的台子后，它仍保持原来的平台类型、敌人数量和敌种。系统只在更远处补生成新平台，不再把整屏候选重新抽一遍。

## 记录与设置

保存最高距离、击破、连跳、分数，以及声音、设备震动、镜头动效设置。使用 `localStorage`；禁用或异常时不会崩溃，只在本次页面会话内保留状态。`file://` 存储表现随浏览器而异，建议正式试玩使用固定的 HTTP(S) 地址。测试中的内存存储单元检查与异常回退均通过；真实 origin 下的持久化不在本次沙箱已验证范围内。

“震”开关控制可选设备触觉，“动/稳”控制镜头震动强度表现；不支持 `navigator.vibrate` 时正常忽略。声音来自 WebAudio 合成，无需音频文件，首次交互后解锁；蓄力声音使用固定 0.00/0.30/0.60/0.90/1.20 秒分层，并在每次新蓄力时从头重置。

## 调试和可重现

静态页面可添加 `?debug=1&seed=112233`。Seed 可用无符号十进制整数，也可使用文字种子。复制调试面板中显示的数字即可复现相同初始随机状态。

调试面板显示 FPS、Seed、难度、局面、状态、力度与敌人剩余预警。R 重开当前 Seed，H 扣血，J 回血，K 推进一个难度阶段，P 暂停。`window.__SPEAR__.snapshot()` 只在使用 `debug=1` 初始化时暴露。

Seed 不等于完整录像：生成还依赖当时的存活时间、平台次数、HP、连跳状态和失误数。同 Seed、相同这些输入、相同路线/时序才会重现同一整局。视觉粒子随机数与世界 RNG 分离，不改变路线生成。

## v1.3 计分规则

- 普通1分台在连续 PERFECT 下仍为 `1 → 2 → 4 → 8 → 16 → 32`；5/10/20分台在自身基础分之上叠加同一套 Perfect Combo 增量。
- 敌人先完成一次攻击，连跳中断；下一次成功飞渡从 1 分重新开始。
- 越过最近台直接飞到第二个平台：本跳额外 `+32`。
- 击杀现在提供小额固定奖励：普通远程兵 +2、铁卫/盾卫 +3、精英 +5；多杀只做加法，不乘倍率。
- 新计分使用新的本地纪录空间，旧版高分不会污染当前榜。

## 内容与商业化

6 类敌人，20 个常规局面模板，另有动态求生调整和三崖追猎轻 Boss。Boss 仍使用同一套投矛操作，允许绕开，不把操作改成别的游戏。背景、美术、粒子、声音均由代码产生；沒有远程图片/CDN 依赖。

广告只是 `AdAdapter` 接口及明确标注的 `MockAdAdapter`。结算上的“演示续命”没有播放真实广告，每局最多一次，恢复 36 HP。奖励翻倍 placement 仅预留接口，不伪造真实广告收益，不改动竞技最高分。真实 SDK、激励回调、账号与发行平台审核尚未接入。

素材升级见 `ASSET_PROMPTS.md`。文档中的 PNG 路径是规划目录，不代表当前版本已经读取不存在的资源。
